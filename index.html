How it works

From the field to the register

The register is a catalogue. It holds metadata plus links. The data stay in open archives, each with its own DOI.

SourcesField surveys, audio, cameras, eDNA, remote sensing, public monitoring, corporate data
In-house analysisProtocols plus tools fit to each data type; versioned scripts; research partners
Open archivesZenodo, PANGAEA, EnviDat, OpenTopography: one DOI per release
Swiss data systemSpecies records to InfoSpecies, on to GBIF; metadata to opendata.swiss
RegisterOne project file per project, in the project's own repository
OutputsFinance dashboards, funder reports, verification packages, OECM evidence
UsersFOEN, cantons, funders, reviewers, researchers, the public

Openness

Three levels, stated per item

Every dataset, agreement plus document carries one of three labels. Nothing is left out silently.

Public

Shown in full

Description, licence plus a link or DOI to the data or document.

On request

Listed, content on request

Parties, type, date plus status are shown. The content goes out on request to register@nfa.ch.

Not disclosed

Listed with a reason

For example personal data, consent not given, exact sites of sensitive species. Fees are never published.
