About the register

How the register works

A public catalogue of NFA nature projects. It shows what each project measures, who measures it, where the data are held, which agreements apply.

Data flow

Seven steps

SourcesField surveys, audio plus cameras, eDNA, remote sensing, public monitoring, public data, corporate data.
In-house analysisAnalysis per data source. Protocols plus tools fit to each data type (Python, R, QGIS), AI-assisted checks, versioned scripts, research partners.
Open archivesZenodo by default, one DOI per release. PANGAEA, EnviDat where they fit. OpenTopography for all drone data. Figshare only if a journal asks.
Swiss data systemSpecies records go to the InfoSpecies data centres, which validate them plus pass them on to GBIF. Dataset metadata go to opendata.swiss.
NFA registerEach project keeps one project file in its own GitHub repository. The register collects these files every night plus publishes them here.
OutputsFinance dashboards, funder reports, verification packages, OECM evidence.
UsersFOEN, cantons, funders, BFI reviewers, Scientific Data, the public.
Disclosure rules

Open by default, closed by exception

Every dataset, agreement plus document is listed, whatever its level. Exceptions carry a reason.

Public

Shown in full

Description, licence plus a link or DOI.

On request

Listed, content on request

Parties, type, date plus status are shown. Write to register@nfa.ch.

Not disclosed

Listed with a reason

One line says why the content stays closed.

What stays closed

  • Fees plus other commercial terms of agreements.
  • Personal data without consent (revised Federal Act on Data Protection, revDSG). People are named only when they agree.
  • Exact sites of sensitive species: published on a coarser grid.
  • Raw audio, which can capture human speech. Detections are published instead.
  • Licensed third-party data that may not be redistributed.

Agreements

For every agreement the register shows the parties, type, status, data licence, claim rights, term plus signing date. The signed document itself goes out on request. Partner logos are shown once the partner has confirmed their use in writing.

Funders get time-limited early access where agreed.

Versioning
Every change is a Git commit in the project repository. Tagged releases of the register can be archived with a DOI.
Add a project

One repository per project

  1. Take the next free number: IDs count upwards across all projects (NFA-001, NFA-002 …), are never reused and never change. Canton plus country go in the project file, not in the ID.
  2. Create a public repository in the naturefinanceaccelerator organisation named ID plus short name, e.g. nfa-001-mellingen, with the topic nfa-project.
  3. Add nfa-project.json, following the schema. The Mellingen repository is the worked example.
  4. Put photos in images/, logos in logos/, the boundary in geo/boundary.geojson.
  5. Add one line for the repository to registry/sources.json in the register repository.
  6. The register collects it at the next nightly run. Errors are listed in the workflow log; the last good version stays online.
